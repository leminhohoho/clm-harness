# AGENTS.md

This is a repository for developing a CLM-style harness with additional capabilities, built for persistent, long running session

# Guidelines

- Default to use TDD for implementation
- Default to not use sub-agents, unless the user said so
- Never auto commit, unless the user said so
- Minimize & optimize code as much as possible
- Write specs as seperate files with format `date_name.md`
- Always include ASCII file tree in a spec that give an overview of the changes to be made
